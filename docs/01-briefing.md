# Briefing do Projeto – [Nome do Sistema]

## 1. Contexto
# Quem é o cliente?
# R: Clínica Veterinária Focinho Feliz, administrada pela Dra. Camila. A clínica oferece atendimento veterinário e possui uma equipe formada pela proprietária, uma recepcionista e um veterinário associado.

# O que a empresa/organização faz?
# R: Presta serviços de atendimento veterinário ao público.

# Qual o tamanho da equipe ou do negócio?
# R: 3 pessoas, Dra. Camila, uma recepcionista e um veterinário associado.

## 2. Problema
# O que não funciona hoje?
# R: Os agendamentos são realizados manualmente em uma agenda de papel, o que pode gerar conflitos de horários. Além disso, o histórico dos animais é armazenado em pastas físicas, sujeitas a perdas, extravios e dificuldades de consulta.

# Como o processo é feito atualmente, sem o sistema?
# R: O processo é feito de forma manual em uma agenda e o histórico armazenado em pasta física.

## 3. Objetivos
# O que o sistema deve alcançar?
# R: Permitir o gerenciamento de agendamentos sem conflitos de horários, armazenar o histórico dos animais digitalmente e disponibilizar a consulta das agendas futuras para a equipe da clínica.

# Qual mudança concreta ele deve provocar na rotina do cliente?
# R: Automatizar o agendamento de consultas e facilitar o acesso ao histórico dos clientes e seus animais (pets).

## 4. Usuários
# Quem vai usar o sistema?
# R: Dra. Camila, um veterinário associado e a recepcionista.

# Existem perfis diferentes de usuário, com permissões ou visões diferentes?
# R: Administrador (Dra. Camila)
# Recepcionista
# Veterinário Associado
# Cada perfil pode possuir permissões específicas de consulta e gerenciamento.

## 5. Escopo incluído
# - Cadastro de animais.
# - Cadastro de clientes (tutores).
# - Agendamento de consultas.
# - Bloqueio de conflitos de horário.
# - Consulta da agenda diária e futura.
# - Histórico de consultas dos animais.
# - Acesso pelo computador.
# - Acesso pelo celular.

## 6. Escopo excluído
# - Funcionalidade sugerida: Cobrança automática pelo cartão de crédito.
# Justificativa: Não é prioridade para a primeira versão do sistema.


## 7. Restrições
# Prazo: Até o final do semestre.
# orçamento: Não informado pelo cliente.
# tecnologia exigida, dispositivos compatíveis, ou qualquer limite conhecido do projeto: Celular e computador

## 8. Critérios de sucesso
# Como o cliente vai saber que o sistema resolveu o problema? 
# - Não ocorrer conflitos de horários nos agendamentos.
# - Todos os históricos dos animais serem armazenados digitalmente.
# - A Dra. Camila conseguir consultar a agenda do dia seguinte pelo celular.
# - Redução da dependência de fichas e pastas físicas.
# - Facilidade de consulta aos dados dos animais.

# Que resultado observável indica sucesso?
# R: Não ocorrem mais conflitos de horários nos agendamentos, os históricos dos animais são armazenados digitalmente sem dependência de pastas físicas e a equipe consegue acessar rapidamente as informações necessárias para o atendimento.
